# E01: What Is Quantum Computing? Your First Quantum Program

Video: https://youtu.be/m67kIjpJ-_o

```
python episodes/E01/first_circuit.py
```

One qubit, one H gate, one measurement, 1000 shots on the AerSimulator. Our real run is in `first_circuit.txt`: `{'0': 510, '1': 490}`. Your counts will differ a little, but stay close to half and half.

Versions: Python 3.13, Qiskit 2.6.1, Qiskit Aer 0.18.2.
